# 人格研究所 · MBTI 风格 32 型人格测试

本项目采用 16 种基础偏好 × A/T 两种自编应对风格，形成 INTJ-A、INTJ-T 等 32 种档案。32 型没有统一的官方定义；A/T 不是官方 MBTI 维度，也不是焦虑、健康或能力诊断。打开 `index.html` 即可运行，无需服务器或依赖。上一级的 `mbti-personality.html` 为全部资源内嵌的单文件版。

## 判定

五级权重为 -2、-1、0、1、2，分别对应非常不符合、不太符合、介于两者、比较符合、非常符合。题目指定倾向 `pole`，与维度左侧字母一致时累加权重，右侧时反向累加。E/I、S/N 总分范围为 -12 至 12，T/F、J/P、A/T 为 -8 至 8。各维度按自身满分独立换算百分比，正数偏向左侧，负数偏向右侧。

主线完成后，对总分为 0 的维度逐个追加二选一情境，最多 5 题。补充选择仅确定该维度字母，不改变主线得分；结果仍显示 50/50。四个基础字母与 A/T 后缀组合形成全部 32 种类型，没有随机分流。

左侧百分比 = round(50 + 总分 / 该维度满分 × 50)，右侧为 100 减左侧。这是自编的方向权重换算，不是准确率、常模分位、诊断指标或经过验证的量表得分。偏好强度为 abs(总分)/该维度满分；结果对接近均衡的维度给出说明。T/F 不等于智力与情绪高低，E/I 不等于社交能力，J/P 不等于自律程度。

A/T 表示本次在压力和评价下的自我感受。A 为笃定型，T 为敏感型，没有优劣；后缀 T 与 T/F 中“思考”的 T 含义不同。
